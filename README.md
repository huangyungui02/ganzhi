# 丙午年干支日历（iOS / iCloud）

范围：2026-02-04 至 2027-02-03，共 365 天。按干支历立春换年，丁未年立春当天不再生成事件。2027-02-04 09:46（北京时间，分钟精度）进入丁未年；由于采用全天日历，本文件截止到前一天。

## 文件选择

- `ganzhi-2026.ics`：合并版，365 条每日干支 + 12 条流月开始事件。
- `ganzhi-2026-daily.ics`：仅每日干支，例如 `己酉`，建议蓝色。
- `ganzhi-2026-monthly.ics`：仅流月，例如 `庚寅月`，建议橙色。节气名称保留在事件详情中。

默认使用 `ganzhi-2026.ics` 合并版，只需导入一个文件。流日标题为「己酉」，流月标题为「庚寅月」，统一使用所属日历的颜色。拆分版保留为可选文件；不要同时导入合并版和拆分版，以免重复。

所有事件均为全天、不占用忙碌时间，无内置提醒。日历的列表或日视图可看到完整标题；月视图能显示多少文字取决于系统版本和屏幕空间。

## 导入和订阅

**Mac 导入（方便同步到 iPhone）：** 在「日历」中新建 iCloud 日历，再通过「文件 → 导入」选择 `.ics`，指定该日历。两个拆分版分别导入两个新日历。iPhone 使用相同 Apple 账户并开启 iCloud 日历同步即可看到。导入是静态副本，重复导入可能产生重复事件。

**iPhone 订阅：** 在「日历 → 日历 → 添加日历 → 添加订阅日历」中填入以下网址。不同 iOS 版本菜单可能略有差异。

```text
https://huangyungui02.github.io/ganzhi/ganzhi-2026.ics
```

也可打开订阅链接：`webcal://huangyungui02.github.io/ganzhi/ganzhi-2026.ics`。这是只读订阅；文件更新后，客户端会定期刷新。

服务器应返回 `Content-Type: text/calendar; charset=utf-8`，允许无需登录直接 GET 文件。合并版订阅一个网址；拆分版订阅两个网址。订阅更新频率由 Apple 日历控制。

Apple 官方说明：https://support.apple.com/zh-cn/guide/iphone/iph3d1110d4/ios

## 历法口径和数据

- 使用北京时间（UTC+8）确定交节日期。日干支按公历零点换日，不使用 23 点换日。
- 年以立春为界；流月以立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒为界，不按农历初一。
- 丙年首月为庚寅，依次辛卯、壬辰、癸巳、甲午、乙未、丙申、丁酉、戊戌、己亥、庚子、辛丑。
- 流月事件只显示在交节当天，详情列出交节时刻。当天交节之前仍属于上一个流月。
- 节气时间采用日本国立天文台公布的分钟数据，转为北京时间（减一小时）；不同历算资料的取整可能相差一分钟。
- 2026 芒种：北京时间 **6 月 5 日 23:48**，注意不能直接采用日本日期 6 月 6 日。
- 日干支以 2000-01-07 甲子日为基准，按六十日连续循环；2026-02-04 为己酉日。
